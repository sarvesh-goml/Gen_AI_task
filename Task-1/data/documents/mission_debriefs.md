## Mission: Ferry Split Disaster Recovery

**Outcome:** Ferry split in half by high-tech weapons; Peter assisted in holding the ship together using webbing before iron thrusters completed the alignment.

**Lessons learned:**
- Web tensile strength under extreme tension was tested to the limit - reinforced the web-fluid formula in subsequent batches to increase elasticity.
- Tony's assistance was needed; relying on solo webbing for a ship-sized structure is risky.

## Mission: Oscorp Lab Break-in Containment

**Outcome:** Multiple mutated hostiles neutralized non-lethally using the Web-Out Protocol (automated web-trap deployment, trapping all hostiles).

**Lessons learned:**
- The Web-Out Protocol works efficiently for crowd control but requires high-capacity web fluid reserves.
- Thermal signature analysis correctly flagged hostiles before visual confirmation, and should be run automatically in any future outbreak.

## Mission: Washington Monument Rescue

**Outcome:** Civilian evacuation completed with zero casualties under the Spider-Man AI's real-time trajectory coordination; high-altitude climbing was required.

**Lessons learned:**
- Prioritizing evacuation and stabilizing the elevator shaft was validated as the correct call.
- Gliding with the web-wings requires a minimum elevation of 50 meters to build adequate lift.

## Mission: Parker Apartment Perimeter Breach Response

**Outcome:** Unauthorized entry into the apartment was detected and contained before any suit hardware could be seen; no active engagement was needed.

**Lessons learned:**
- The inner-vault biometric/web lock correctly rejected a forged credential; the security layer described in the practical-support notes performed exactly as designed.
- Response time from alert to full lockdown was 4 seconds - acceptable, but a 2-second target should be the goal.
